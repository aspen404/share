# Share

Random one-off pages the Cardoso family wants to look at together — comparisons, shortlists, decision aids, etc. Each subdirectory is a self-contained, single-file static site.

- `dentists/` — Family dentist shortlist (May 2026), zip codes 92127 / 92128 / 92129.

The root `index.html` is the chooser that lists available pages.

## Local preview

```
open index.html
```

## Deploy

GitHub Pages, source = `main` branch / `/` (root). Hosted at https://aspen404.github.io/share/.

Commit and push directly to `main` — no feature branches for this repo (same exception as the `vacations` repo: personal static site, no review process, GH Pages deploys from main).
